🚀 HOW TO RUN

  Option 1: Download ZIP and Run Locally
  ────────────────────────────────────────
  1. Click three dots (⋯) → "Download ZIP"
  2. Extract to your computer
  3. pnpm install
  4. Terminal 1: pnpm dev --filter @forge/api
  5. Terminal 2: pnpm dev --filter @forge/web
  6. Open http://localhost:5173

  Option 2: Deploy to Vercel
  ────────────────────────────
  1. Click "Publish" button
  2. Follow prompts to deploy
  3. Get live URL
